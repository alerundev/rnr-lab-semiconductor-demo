# 알엔알랩(주) 반도체 장비 소개 — 비공식 독립 데모

공식 사이트 교체 또는 공식 제작물이 아닌 한국어 반응형 랜딩페이지입니다. 자체 제작 CSS 개념 그래픽만 사용하며 공식 로고·사진·브랜드 자산은 포함하지 않습니다.

## 실행

```bash
npm ci
npm run dev
```

## 배포

```bash
npm ci
npm run build
```

- 저장소 루트: 웹 앱 소스 및 `package.json`
- 빌드 명령: `npm run build`
- 정적 게시 디렉터리: `dist`
- Node.js 20.19+ 또는 22.12+ 권장 (Vite 6)
- 라우팅이나 서버 환경 변수 필요 없음
